# Uso de inteligencia artificial generativa

Este documento sirve para completar el requisito del enunciado sobre uso de IA
generativa.

Sistema usado:

- Codex, modelo GPT-5, integrado en el entorno de desarrollo.

Uso realizado:

- Lectura y resumen del enunciado del trabajo.
- Propuesta de arquitectura del proyecto.
- Generacion asistida de codigo Python para reglas de Otelo, UCT, red neuronal
  de valor, scripts de entrenamiento y experimentacion.
- Generacion asistida de pruebas unitarias y documentacion inicial.

Prompts principales:

- "Lee el pdf y dime como crees que se podria hacer el mejor proyecto posible".
- "Ejecutalo".

Revision humana necesaria:

- Comprobar que cada integrante entiende el codigo completo.
- Ejecutar experimentos con suficiente numero de partidas.
- Sustituir los resultados de ejemplo por resultados definitivos.
- Preparar la defensa explicando reglas, UCT, etiquetado de datos y red
  neuronal.
